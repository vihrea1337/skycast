**Готово, когда:** в авиарежиме приложение показывает последние данные с пометкой времени обновления.

## Этап 4 — Города и настройки (~4–5 вечеров)

- [ ] Геолокация: FusedLocationProvider + запрос разрешения `ACCESS_COARSE_LOCATION`, graceful fallback на поиск

**Готово, когда:** можно жить с приложением: свой город, свои единицы, всё переживает перезапуск.

### Правила по ходу всего проекта

- Коммиты — [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `refactor:`, `test:`); ветки `feature/<имя>` → PR в `main` (даже соло — привычка + история для портфолио).
- Не тащить библиотеку, пока не нужна. Не начинать следующий этап, пока текущий не «Готово, когда».
- Все версии библиотек — актуальные на момент подключения (проверять в Android Studio / Maven Central), в доках версии намеренно не зафиксированы.

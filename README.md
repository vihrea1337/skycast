# WeatherApp (рабочее имя — SkyCast)

Пет-проект для портфолио уровня middle-junior: Android-приложение погоды + виджет домашнего экрана.

**Стек:** Kotlin · Jetpack Compose · Glance (виджет) · Hilt · Retrofit + kotlinx.serialization · Room · DataStore · WorkManager · Open-Meteo API · OpenAPI/Swagger · GitHub Actions.

## Как устроена эта папка

```
WeatherApp/
├── README.md          ← этот файл (позже заменится на README самого приложения)
├── docs/              ← проектная документация: единый план + роадмап
├── archive/           ← zip с исходными подокументами (по файлу на модуль)
└── (сюда же Android Studio создаст сам проект: app/, core/, gradle/, ...)
```

Эта папка = будущий git-репозиторий. Проект в Android Studio создаётся **прямо в корень** этой папки, `docs/` остаётся рядом с кодом — это плюс для портфолио.

## Порядок чтения документации

| Файл | Что внутри |

| `docs/00-roadmap.md` | **С чего начинать.** Этапы 0–9 с чек-листами и критериями готовности |

| `archive/docs-sources-2026-07-08.zip` | Исходные подокументы (по одному MD на модуль) — на случай, если понадобятся по отдельности |
